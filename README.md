## Призначення
Програма призначена для обчислення та класифікації підсумкового результату навчання студента на основі балів за самостійну роботу та опитування. 

## Вхідні дані та правила
1. **Перевірка читання потоку (Рівень 1):** Якщо зчитування `cin` зазнало невдачі (введено не цілі числа), виводиться помилка: `"Помилка: введіть цілі значення балів"`.
2. **Перевірка діапазонів (Рівень 2):** Якщо `independent` $< 0$ або $> 40$, або `quiz` $< 0$ або $> 60$, виводиться помилка: `"Помилка: значення поза допустимими межами"`.
3. **Класифікація результату (взаємовиключні гілки):**
   * Якщо `independent < 20` $\rightarrow$ `"потрібно посилити самостійну роботу"`
   * Інакше, якщо `total < 50` $\rightarrow$ `"підсумок нижче порога"`
   * Інакше, якщо `total <= 79` $\rightarrow$ `"стабільний результат"`
   * Інакше, якщо `total >= 80` $\rightarrow$ `"високий результат"`

## Перевірки
Для підтвердження коректності роботи алгоритму виконано ручне тестування граничних та типових значень:

| № | Вхідні дані (`independent`, `quiz`) | Що перевіряється | Очікуваний результат |
|---|---|---|---|
| **1** | `15 30` | `independent < 20` (перша умова) | `потрібно посилити самостійну роботу` |
| **2** | `20 25` | `independent >= 20`, але `total = 45 < 50` | `підсумок нижче порога` |
| **3** | `20 30` | Граничне значення `total = 50` | `стабільний результат` |
| **4** | `30 45` | Типовий випадок (`total = 75` в межах 50-79) | `стабільний результат` |
| **5** | `30 49` | Верхня межа `total = 79` | `стабільний результат` |
| **6** | `30 50` | Нижній поріг високого результату (`total = 80`) | `високий результат` |
| **7** | `-5 30` | Недопустиме значення (від'ємні бали) | `значення поза допустимими межами` |
| **8** | `45 10` | Перевищення верхньої межі `independent` (> 40) | `значення поза допустимими межами` |
| **9** | `abc 20` | Некоректний тип даних (символи замість чисел) | `введіть цілі значення балів` |
